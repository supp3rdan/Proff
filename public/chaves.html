Para que serve a chave?

O Proff usa inteligência artificial de três empresas que oferecem uso gratuito: Google Gemini, Groq e OpenRouter. A chave de API é como uma senha que libera esse uso para você.

  • Basta uma chave para o Proff funcionar. Recomendamos começar pelo Google Gemini.
  • Com duas ou mais, o Proff troca de provedor sozinho quando um atinge o limite, e confere o gabarito com um modelo diferente.
  • Nenhuma delas pede cartão de crédito.
  • Se você não colar nenhuma chave, o Proff usa as chaves padrão do projeto (quando houver). Elas são compartilhadas por todos os professores, então podem atingir o limite do dia.

Recomendado

1. Google Gemini

Precisa de uma conta Google (Gmail). Cota diária generosa.

  1. Acesse o Google AI Studio → API keys e entre com sua conta Google.
  2. Aceite os termos de uso, se aparecerem.
  3. Clique em Create API key (Criar chave de API). Se ele pedir um projeto, escolha o sugerido ou crie um novo.
  4. Copie a chave gerada (começa com AIza).

No plano gratuito, o Google pode usar os pedidos para melhorar os produtos dele. Não coloque dados de alunos nas observações.

2. Groq

Pode entrar com Google, GitHub ou e-mail. Muito rápido.

  1. Acesse o GroqCloud → API Keys e crie sua conta ou entre.
  2. Clique em Create API Key.
  3. Dê um nome (ex.: proff) e confirme.
  4. Copie a chave na hora (começa com gsk_): ela só aparece uma vez.

3. OpenRouter

Dá acesso a vários modelos gratuitos (até 50 pedidos por dia sem créditos).

  1. Acesse o OpenRouter → Keys e crie sua conta ou entre.
  2. Clique em Create API Key, dê um nome e confirme. Se quiser, defina um limite de crédito: com limite 0, ela nunca gera cobrança.
  3. Copie a chave na hora (começa com sk-or-).
  4. Em Settings → Privacy, permita o uso de modelos gratuitos. Sem isso, os modelos :free podem recusar o pedido.

Colar a chave no Proff

  1. Abra o Proff.
  2. Clique em Chaves de API, logo abaixo do campo de observações.
  3. Cole cada chave no campo do provedor correspondente. Ela é salva na hora.
  4. Para voltar às chaves padrão do projeto, apague os campos ou clique em Voltar às chaves padrão.

A chave fica salva só no navegador em que você colou e vai direto para o provedor de IA, sem passar por nenhum servidor do Proff. Em computadores compartilhados (como os da escola), apague a chave ao terminar.

Para quem mantém o Proff: chaves padrão

As chaves padrão não ficam no código, porque o repositório e o site são públicos. Elas ficam guardadas como segredos no GitHub e são escritas no arquivo config.js só na hora da publicação.

  1. No repositório, abra Settings → Secrets and variables → Actions.
  2. Clique em New repository secret e crie um segredo para cada chave que tiver: GEMINI_API_KEY, GROQ_API_KEY e OPENROUTER_API_KEY.
  3. Em Actions → Publicar no GitHub Pages, clique em Run workflow para publicar de novo com as chaves.

Quem abrir o site consegue ver as chaves padrão no arquivo config.js. Como não há cartão cadastrado, não existe cobrança, mas outra pessoa pode gastar a cota grátis. Para proteger a chave do Gemini, restrinja-a ao endereço do site:

  1. Abra o Google Cloud → Credenciais com a mesma conta e o mesmo projeto da chave.
  2. Clique na chave e, em Restrições de aplicativos, escolha Sites.
  3. Adicione https://supp3rdan.github.io/* e salve. A chave passa a funcionar só no Proff publicado.

Groq e OpenRouter não têm esse tipo de restrição. No OpenRouter, um limite de crédito 0 na chave garante que ela nunca gere cobrança. Se perceber uso estranho, apague a chave no site do provedor e crie outra.
